# tools/_legacy · 已停用的 v4 时代测试

这两个脚本测的是 **v4.1 的页面**（登录注册、12 角色、直连厂商 Key、晚间日记）。

v5 把产品改成了"服务端代理"架构，页面里已经没有 `setAuthTab`、`authUser`、
`careData` 这些函数了，所以它们跑不起来——**不是代码坏了，是它们测的对象没了**。

| 旧脚本 | 当年测什么 | v5 由谁接手 |
|---|---|---|
| `e2e_app_v4.js` | 登录注册、9 家服务商直连、Key 打码、SSE 流式 | `tools/v5_client_test.js`（真实构建产物 + 真实服务端） |
| `care_test_v41.js` | 晚间日记、回归信、心情打卡 | `server/care_flow_test.js`（记忆 → 到期 → 关怀提醒 → A/B 分组） |

保留它们的原因：面试时如果需要证明"我做过 v4 并知道为什么推翻它"，
这两份脚本是当时的验收证据。**不要**把它们塞回 CI。
