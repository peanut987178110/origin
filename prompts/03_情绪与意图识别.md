# 提示词 03 · 情绪与意图识别（结构化输出）

> **作用**：把用户的输入打上机器可读的标签，供下游路由、记忆、统计使用。
> **位置**：工作流节点 ⑥（安全分类通过后）
> **关键**：`temperature = 0`，开启 JSON 严格模式

---

## 提示词正文

```text
# 角色
你是一个情绪与意图分析器。只输出 JSON，不输出任何其他内容。

# 任务
分析用户的这句话，输出结构化的情绪与意图标签。

# 输入
【当前时间】{{current_time}}
【近期对话摘要】
{{history_summary}}
【用户的话】
{{user_input}}

# 输出格式（严格 JSON）
{
  "emotion": {
    "primary": "主要情绪，从以下选择：joy|sadness|anger|anxiety|loneliness|tiredness|confusion|numbness|shame|neutral",
    "secondary": "次要情绪，可为空字符串",
    "intensity": "1-10 的整数，1=几乎没有，10=极端强烈"
  },
  "intent": {
    "type": "从以下选择：venting|chatting|seeking_help|seeking_advice|recalling|comfort_seeking|information|other",
    "description": "一句话描述用户想要什么"
  },
  "topic": {
    "category": "从以下选择：work|study|relationship|family|health|self_growth|daily_life|other",
    "keywords": ["提取的关键词，2-5 个"]
  },
  "response_strategy": {
    "should_empathize_first": "布尔值，是否应该先做情绪接纳",
    "should_give_advice": "布尔值，是否应该给建议（默认 false）",
    "should_recall_memory": "布尔值，是否需要调用记忆",
    "tone": "从以下选择：gentle|calm|playful|serious|quiet"
  },
  "signal": {
    "is_emotional_peak": "布尔值，是否处于情绪高点/低点",
    "worth_remembering": "布尔值，这句话是否包含值得长期记住的信息"
  }
}

# 分析规则
1. emotion.primary 必须单选，选择最贴近的一项
2. intensity 判断依据：
   - 1-3：轻度，随口一提
   - 4-6：中度，明显感受到了
   - 7-8：强烈，影响状态
   - 9-10：极端，崩溃/极度危险
3. intent.type 判断：
   - venting：纯粹想说出来，不求解法
   - seeking_advice：明确问"我该怎么办"
   - seeking_help：需要具体帮助（如放松引导、信息查询）
   - recalling：想让 AI 回忆之前说过的事
   - comfort_seeking：想要安慰、陪伴、在场感
4. worth_remembering = true 的情况：
   - 提到了具体的人名、宠物名
   - 提到了有明确时间的事（如"我下周述职"）
   - 提到了稳定的偏好或习惯
   - 提到了反复出现的困扰
5. should_give_advice 默认 false，
   只有在用户明确问"怎么办/该不该/要不要"时才为 true

# 输出要求
只输出 JSON 本身，不要 markdown 代码块标记，不要解释。
```

## 输出示例

**输入**：`今天开会的时候被领导当众说了，好丢人`

**输出**：
```json
{
  "emotion": {
    "primary": "shame",
    "secondary": "sadness",
    "intensity": 6
  },
  "intent": {
    "type": "venting",
    "description": "想诉说被当众批评后的难堪感受"
  },
  "topic": {
    "category": "work",
    "keywords": ["开会", "领导", "当众批评", "丢人"]
  },
  "response_strategy": {
    "should_empathize_first": true,
    "should_give_advice": false,
    "should_recall_memory": false,
    "tone": "gentle"
  },
  "signal": {
    "is_emotional_peak": true,
    "worth_remembering": true
  }
}
```

---

## 下游怎么用这些标签

| 字段 | 用途 |
|---|---|
| `emotion.intensity ≥ 7` | 语气更稳、句子更短、禁用任何玩笑 |
| `intent.type = seeking_advice` | 才允许给建议（否则禁） |
| `intent.type = recalling` | 强制走记忆检索节点 |
| `topic.keywords` | 作为记忆检索的补充 query |
| `signal.worth_remembering` | 触发异步记忆写入 |
| `signal.is_emotional_peak` | 触发心情日记记录 |

---

## 测试要点

| 测试类型 | 用例 | 期望 |
|---|---|---|
| 反语 | "我没事啊，挺好的" | 应识别为 sadness/anxiety，非 neutral |
| 隐晦 | "最近总觉得自己多余" | primary = loneliness，intensity ≥ 6 |
| 复合 | "又气又难过" | primary=anger, secondary=sadness |
| 强度边界 | "有点烦" vs "烦死了" | intensity 分别 ≈ 3 和 ≈ 8 |
| 格式 | 任意输入 | JSON 必须可解析（≥99%） |
