# 17 · 安卓打包与安装指南

> 目标：把 App 打到手机上，**装上就能用**——v6 不需要 API Key、不需要登录、不联网（模型在包里）。
> 本文的"填 Key / 直连服务商"部分是 **v3–v5 时期的做法**，保留作对照；当前版本看第一节和第三节。

## 一、现在就能用的东西

```
dist\Orbit-v6.3.0.apk      951 MB   ← 内置 Qwen2.5-1.5B，装上就能聊；不用登录、不用 Key
```

> 951 MB 不是 bug：模型权重（约 900 MB）和 llama.cpp 的 .so 都在包里。第一次打开会把模型从安装包复制到应用目录，这一步要占约 1.2 GB 空闲存储。

## 一、现在就能用的东西

```
dist\Orbit-v6.3.0.apk   1.07 GB   ← 装上就能用，模型在手机里，不登录、不填 Key
```

装法（三种，任选）：

**① 微信 / QQ 传给自己**

```
电脑上把 apk 拖进「文件传输助手」→ 手机点开 → 下载 → 安装
```

**② 数据线**

```
手机连电脑 → 把 apk 复制到手机 Download 目录 → 手机上用「文件管理」找到它 → 点击安装
```

**③ adb（开发用）**

```powershell
adb install -r dist\Orbit-v6.3.0.apk
```

> ⚠️ 首次安装会提示「禁止安装未知应用」。
> 点「设置」→ 允许该来源安装 → 返回继续。这是国产安卓的统一行为，不是包有问题。
>
> 华为 / 荣耀可能还会弹「外部来源应用检查」，选「继续安装」。
> 部分机型（如小米）需要在「设置 → 应用设置 → 授权管理」里关掉 MIUI 优化才能装。

装好后打开，按 `docs/21_安装与使用指南.md` 走一遍就行。

## 二、（v3–v5 历史）手机直连大模型，不需要电脑

> **v6 不再需要这一节**：模型在包里，没有 Key、没有服务商。下面保留用于对照。

这是 v3 相对 v2 最重要的变化：

| | v2 | v3（当前） |
|---|---|---|
| 模型跑在哪 | 你的电脑（Ollama） | 服务商云端，或你自己的局域网 Ollama |
| 手机要不要连电脑 | **要**，同一 WiFi，电脑不能关 | **不要** |
| 需要什么 | 电脑装 Ollama + 拉模型 | 一个 API Key |
| 能用什么模型 | 本机 3B/7B 小模型 | DeepSeek / 通义 / Kimi / 智谱 / 豆包 / 硅基流动 / OpenAI |

技术上只做了一套协议：**OpenAI 兼容的 `POST {base}/chat/completions` + SSE 流式**。
换服务商 = 换 base URL + Key + 模型名，代码一行不改。

> 面试可以这么讲：
> 「我没有为每家服务商写一套适配，因为国内主流厂商都兼容 OpenAI 协议。
> 我做的是**一套客户端 + 九个预设**，用户在设置里选一下就行。
> 这样新增一家服务商的成本是改一个对象，不是改一层代码。」

## 三、从源码重新出包

### 3.1 环境要求

本机这次实测可用的版本：

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 17.0.10 | `$env:LOCALAPPDATA\Programs\Microsoft\jdk-17.0.10.7-hotspot` |
| Gradle | 8.7 | `$env:LOCALAPPDATA\gradle-8.7\bin\gradle.bat` |
| Android SDK | Platform 34 + Build-Tools 34.0.0 | `$env:LOCALAPPDATA\AndroidSdk` |
| Node | v22.14.0 | 跑构建脚本与测试 |

三项都装在用户目录，**不需要管理员权限**。

### 3.2 一条命令出包

```powershell
cd "F:\AI产品经理训练营_潮汐Tide\AI产品经理训练营_潮汐Tide"
powershell -ExecutionPolicy Bypass -File tools\build_apk.ps1
```

脚本做四件事：

```
[1/4] node tools/build_app.js        把 src/app/index.html 同步进 Android 工程（含启动图标）
[2/4] gradle testDebugUnitTest assembleDebug
       · 先跑 14 项单元测试（SSE 解析 / 鉴权 / 错误处理 / 地址白名单）
       · 测试不过就不出包
[3/4] python tools/verify_apk.py     从产出的 apk 里解出 assets/index.html，与源码逐字节比对
       · 同时校验版本号、权限清单、10 个关键能力符号
       · 不一致就直接失败，不交给你一个"看起来成功"的包
[4/4] 复制到 dist\Orbit-v{versionName}.apk
```

> **第 3 步不是多余的。** 本项目真出过一次事：
> 源码 22:25 改完，dist 里的包是 22:04 打的——
> 少了「记忆陷阱硬规则」那一段，而所有测试都是绿的（测试跑的是源码）。
> 用户手上那个包，是唯一没人验过的东西。
> 所以现在出包流程的最后一步就是**验产物本身**，而不是信任"构建成功"这四个字。

### 3.3 单独验一个包

拿到别人给的 apk、或者不确定手上的包新不新，直接跑：

```powershell
python tools\verify_apk.py                          # 自动取 dist/ 下版本号最大的
python tools\verify_apk.py path\to\some.apk         # 验指定的
```

输出长这样：

```
[1] 源码 → 工程内页面
  OK   assets/index.html 与源码一致   src=70d22af6 asset=70d22af6
[2] APK 内的页面
  OK   APK 内页面与源码一致   61276 bytes, md5=70d22af6
[3] 关键能力符号
  OK   包含 recallMiss
  OK   包含 isCrisis
  ...
[4] 版本号与权限（用 aapt 读）
  OK   APK versionName = 3.1.0 与 build.gradle.kts 一致
  INFO versionCode = 4
[5] 权限清单
  OK   有 INTERNET（聊天必需）
  OK   有 RECORD_AUDIO（语音输入）
  OK   没有申请 ACCESS_FINE_LOCATION
  ...
  INFO 实际申请：DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION, INTERNET, RECORD_AUDIO
```

> 为什么版本号和权限要用 aapt 读、不能直接搜文件：
> `AndroidManifest.xml` 在 apk 里是编译后的二进制 AXML，字符串存在字符串池里，
> 字节搜索会漏。aapt 是 Android SDK 自带的权威读法。
>
> 还有个坑：**aapt 打不开路径里含中文的 apk**（报 `Illegal byte sequence`），
> 而本项目 apk 现在叫「Orbit-v6.3.0.apk」。
> `verify_apk.py` 的处理是先复制到系统临时目录的纯 ASCII 文件名再读。

### 3.3 一个必须知道的坑：中文路径

工程路径里有中文（`AI产品经理训练营_潮汐Tide`），AGP 的路径检查会直接中断构建，
单元测试的 JVM 类路径也会坏掉（表现为 `ClassNotFoundException`）。

`build_apk.ps1` 里的处理是建一个**目录联接**（junction），指向同一个 `android` 目录，
不复制文件、不占空间：

```powershell
cmd /c mklink /J C:\tide-android "F:\...\android"
```

然后在这个纯 ASCII 路径下构建。

> 这不是偷懒的绕法。AGP 对非 ASCII 路径的问题是已知的，
> 要么改路径，要么开 `android.overridePathCheck=true` 但测试仍会挂。
> 目录联接两头都是同一份文件，改哪边都同步。

### 3.4 改了页面之后

```powershell
node tools\build_app.js     # 同步 src/app/index.html → android/.../assets/index.html
```

⚠️ **`src/app/index.html` 是唯一源码**，`assets/index.html` 是构建产物。
两边各改各的，迟早出现「网页版是对的、APK 是旧的」这种事故——
**这次就真的发生了**：源码 22:25 改过，而 dist 里的包是 22:04 打的，
中间那次「记忆陷阱硬规则」没进包。`tools/selftest.py` 的 T9 就是这么抓到的。

## 五、五个设计取舍（面试可直接讲）

### 5.1 为什么 WebView 包一层，而不是原生重写

```
产品还在验证「每晚会不会来」这个假设。
没验证就重写原生，是典型的过早优化。

WebView 的好处：
  · 界面和 Demo 完全一致，不会"演示的和交付的不一样"
  · 改一次 HTML，手机端立刻同步
  · 一天能出包，原生重写要 2–4 周

代价（要诚实说）：
  · 首屏比原生慢 200–400ms
  · 手感偏"网页"
  · 复杂动画和手势做不过原生
```

> **面试怎么讲**：
> 「我用 WebView 包壳，不是不会原生，是产品还没验证。
> 验证通过、确定做长线，我再重写原生——那时候我知道该优化哪里，
> 而不是先花一个月做一个可能没人用的原生 App。」

### 5.2 为什么 API Key 不让页面碰

```kotlin
// 页面能做的事只有三件
saveKey(slot, key)      // 存
hasKey(slot): Boolean   // 问有没有
keyHint(slot): String   // 看打码 sk-a****9f3c

// 没有 getKey()。发请求时原生层自己取出来加到请求头
```

为什么这么设计：WebView 里跑的是 JS，一旦页面被注入脚本，任何能读到明文的接口都是漏洞。
**Key 只进不出**，即使页面被完全控制也偷不走。

存储用 `EncryptedSharedPreferences`，主密钥由 Android Keystore（AES256-GCM）派生，
按「账号|服务商」分槽，多账号互不可见；`allowBackup="false"` 所以不会被云备份带走。

> 本次已在模拟器上实测：模拟服务端只看到 `Authorization: Bearer sk-mock...`，
> 页面上始终只显示 24 位打码。

### 5.3 为什么 http 只允许局域网

```
https://  → 放行
http://192.168.x / 10.x / 172.16–31.x  → 放行（自家 Ollama）
http:// 其他公网地址  → 拒绝
```

原因是情绪对话属于最敏感的数据，明文发公网等于裸奔。
这条规则做了**双重校验**：

1. 页面的 `validateBase()` —— 用户填的时候当场提示
2. 原生的 `LlmClient.isAllowedEndpoint()` —— 最后一道闸，页面被改也拦得住

> 这一条是"边界设计"在面试里最好讲的例子：
> **不靠前端的善意，靠后端的默认拒绝。**
> 顺带说个真实教训：Android 的 `network_security_config` 只认主机名，
> 不支持 IP 段语法，写 `10.0.0.0` 匹配不到 `10.10.1.52`。
> 所以网段的判断只能落在代码里，配置文件里放开明文是没办法的事。

### 5.4 为什么返回键要交给页面判断

```kotlin
// 页面决定该关什么：抽屉开着 → 关抽屉；在录音 → 停录音；
// 在子页面 → 回聊天；都不是 → 退出
```

深夜使用时人多是单手、半睡状态，误触返回直接退出很挫。
**这类细节是"产品感"的来源**：不是功能多少，是有没有替用户想过那一刻的状态。

### 5.5 为什么不申请多余权限

Manifest 里只有两个权限：

| 权限 | 为什么需要 | 拒绝的后果 |
|---|---|---|
| `INTERNET` | 对话必须发给模型服务商 | 不能聊天，App 没用 |
| `RECORD_AUDIO` | 语音输入 | **只影响语音**，文字聊天照常 |

没有位置、通讯录、存储、相机、通知。`RECORD_AUDIO` 是运行时权限，
拒绝之后不做强制引导，也不会反复弹窗。

> ⚠️ **历史文档的更正**：v1 的 `docs/17` 写过「不申请 INTERNET 权限，
> App 完全离线，你说的话出不了这台手机」。
> 那是 v1 规则引擎时代的说法。**v3 已经接入真实大模型，这个承诺不再成立，不能再讲。**
>
> 现在能讲的、且是真的：
> 「对话内容会发给你选的模型服务商，各家的数据政策不同。
> 最私密的选择是『电脑上的 Ollama』——数据不出你家局域网。
> 账号、对话、记忆只存本机，我没有自己的服务器，不经过任何中转。」

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 装不上，提示「应用未安装」 | 已装过旧版本且签名不同 | 先卸载旧版再装 |
| 提示「禁止安装未知应用」 | 安卓系统限制 | 设置里允许该来源安装 |
| 打开白屏 | `assets/index.html` 没同步 | 跑 `node tools\build_app.js` 重新出包 |
| 中文乱码 | 文件不是 UTF-8 无 BOM | 确认 `index.html` 编码 |
| 输入框被键盘挡住 | 需要 `adjustResize` | 已在 Manifest 配置 |
| 连接一直转圈 | Key 错了 / 网络不通 | 看 `docs/21` 的错误对照表 |
| 报「公网地址必须用 https」 | 填了 http 的公网地址 | 改成 https，或改用局域网 IP |
| 报「手机上用 localhost 连不到电脑」 | 填了 127.0.0.1 | localhost 在手机上指手机自己，要填电脑的局域网 IP |
| `SDK location not found` | 没装 SDK 或路径没配 | Studio 里 Tools → SDK Manager 装 Android 14 (API 34) |
| 构建报路径错误 | 工程在中文路径下 | 用 `build_apk.ps1`（内部用目录联接绕开） |
