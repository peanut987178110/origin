# 潮汐 Tide PRD v4.0.0：手机内置模型版

文档日期：2026-11-02。状态：已构建，可进入设备验收，未公开发布。

> 当前交付口径（v4.0.0，2026-11-02）：默认使用安装包内置 Qwen2.5-0.5B-Instruct Q4_K_M，通过 llama.cpp 在手机 CPU 推理，无需 API Key、电脑或首次联网下载。云 API 为设置中的可选模式。安装包约 485 MB，仅支持 arm64-v8a / x86_64，Android 7.0 及以上。首次对话需在应用私有目录准备模型，建议至少预留 1.5 GB 空间。
>
> 本地模式目前为整段返回、最近四条非系统消息上下文、最多约 120 个生成 token；不自动提炼长期记忆。旧文中的云端流式、每四轮记忆抽取、向量检索、12 节点安全分类、自动告警、留存和成本指标，分别属于可选云功能或教学规划，不能统称为当前离线实装能力。小模型可能产生重复、不当或不准确回答；词表不能保证危机零漏判。系统语音服务可能联网，文本推理在本机执行。
>
> 验证状态：v4 构建成功，原有网络客户端 14 项单元测试通过，APK 页面与源码一致性检查通过。尚未完成 v4 手机/模拟器断网生成实测，旧版测试结果不能作为本地推理验收证据。

## 用户与目标
面向有夜间独处、轻量倾诉需求的成年人。目标路径：安装 APK → 本地注册 → 选角色与头像声音 → 直接聊天。默认路径不出现 Key 或模型服务商配置。年龄限制是产品定位，当前未实现可靠年龄核验。

## 实际功能及验收
| 功能 | 当前实现 | 验收要求 |
|---|---|---|
| 文本生成 | GGUF 内置、JNI 调 llama.cpp CPU | 飞行模式冷启动后有与输入相关的模型回复，不能以固定模板代替 |
| 首次准备 | 后台复制模型到私有文件，完成后原子重命名 | 中断重启可恢复，不使用半文件；空间不足明确报错 |
| 角色 | 12 个角色，6 组、18 头像 | 选择后角色提示进入模型 |
| 上下文 | 最近四条非系统消息，每条最多 400 字符 | 多轮测试包含用户上下文；超过上下文预算明确提示 |
| 返回方式 | 本地生成完一次显示，最大 120 token | 等待期间不重复发送，失败恢复按钮 |
| 云模型 | 保留用户主动配置的兼容 API | 默认本地不依赖它，不静默发送对话 |
| 记忆 | 本地模式关闭自动抽取 | 不宣传长期记忆或向量检索已实现 |
| 风险 | 本地危机关键词及固定资源提示 | 验证命中分支不运行常规生成；漏判率仍需评测 |
| 语音 | Android 系统识别与 TTS | 无服务/拒绝麦克风不影响文本；系统服务可能联网 |

## 数据与隐私
账号、对话和设置保存在本机。当前本地密码散列不构成强身份安全机制。清空对话不等于删除长期记忆或所有数据。卸载会删除应用数据。云模式会发送提示词、历史与已有记忆至用户所填地址；API Key 存储存在未加密降级路径，不能承诺绝对安全或注入脚本无法滥用。

## 设备与性能
Android 7.0+，64 位 ARM 手机；x86_64 用于模拟器。至少预留 1.5 GB 存储，内存、首轮时延和连续使用温升需真机测量，不承诺固定秒数。0.5B 模型能力明显低于云端大模型，不承担诊断或紧急救援。

## 学习与后续规划
学习时先安装 v4 并记录设备证据，再读 LocalEngine.kt、cpp/tide.cpp 及页面 localChat。demo/ 规则引擎用于教学对照，不代表本地模型。RAG、MCP、独立安全分类、后台告警和商业化均作为后续练习，须分别给出代码、测试与结论。
