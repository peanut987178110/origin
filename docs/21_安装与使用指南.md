# 21 · 安装与使用指南（给拿到 APK 的人）

> 这份文档是写给**不懂技术的人**的。把 `dist\潮汐Tide-v3.1.0.apk` 和这份文档一起发出去就行。
> 开发者要看构建和架构，去 `docs/17`；要看模型接入细节，去 `docs/20`。

---

## 一、这是什么

一个深夜陪伴 App。它不联网到"我们"的服务器——**它直接连你自己选的大模型**。

所以它有两个特点：

1. **要你自己准备一个 API Key**（一次，3 分钟）
2. **你的对话直接发给你选的服务商，不经过任何中转**

没有 Key 也能装、能注册、能看界面，只是聊不了天。

---

## 二、装到手机上

### 第一步：把文件弄到手机

三种方法，选一个：

**微信 / QQ（最简单）**

```
电脑上打开微信 → 找到「文件传输助手」→ 把 apk 拖进去
手机上打开微信 → 文件传输助手 → 点那个 apk → 下载
```

**数据线**

```
手机连电脑 → 传输文件 → 把 apk 复制到手机「Download」文件夹
手机打开「文件管理」→ 下载 → 点 apk
```

**网盘**

```
传到百度网盘 / 阿里云盘 → 手机上下载 → 点开
```

### 第二步：允许安装

第一次装会跳出提示，大概长这样：

```
┌────────────────────────────────┐
│ 为了安全，你的手机禁止安装      │
│ 来自此来源的未知应用            │
│                                │
│      [取消]      [设置]         │
└────────────────────────────────┘
```

点 **设置** → 找到「允许来自此来源」的开关打开 → 返回 → 再点一次 apk。

> 这不是安装包有问题，是安卓对**所有**非应用商店的安装都这样拦。
> 装上之后不会再问。

### 第三步：打开

桌面出现一个紫蓝色圆形图标，名字叫「潮汐」。

---

## 三、第一次打开：四步走完

### ① 注册

随便起个用户名（2 个字以上）和密码（4 位以上）。

> 这个账号**只存在你手机里**，没有注册服务器，换手机就没了。
> 忘了密码没法找回——卸载重装就是新账号（历史对话也会一起没）。

### ② 选一个陪你说话的人

12 个角色，按你现在的状态分组。比如：

- 深夜睡不着 → **潮汐**（话少、有分寸）或 **小满**（温柔、慢）
- 上班受了气 → **阿岸**（护短，先替你不平）
- 学生备考 → **小鱼**（同龄学姐）或 **木老师**（不骂人的老师）
- 感情受伤 → **晚晚**（闺蜜）或 **阿野**（哥们）
- 一个人在外地 → **奶奶**（会问你吃饭没）
- 只想轻松聊 → **豆豆**（开心果）或 **凌**（理性）

之后随时能在设置里换。

### ③ 头像和声音

挑个头像；自动朗读默认开着，语速音调可以调，点「试听一句」听听看。
不想听就把「自动朗读回复」关掉。

### ④ 连接大模型（这一步最关键）

页面长这样：

```
服务商        [DeepSeek        ▾]
              中文好、价格低，陪伴场景首选 · Key 在 platform.deepseek.com 申请

接口地址      [https://api.deepseek.com/v1      ]   ← 已经填好了，不用动

API Key       [                                  ]   ← 只有这里要你填

模型          [deepseek-chat                 ]   ← 已经填好了，不用动

温度          [0.8]

              [ 保存并测试连接 ]
```

**你要做的只有一件事：把 API Key 粘进那一格。**

怎么拿到 Key，见下一节。

粘好之后点「保存并测试连接」，看到这个就成功了：

```
✓ 连接成功    模型回复：你好呀，今天过得怎么样？
```

然后点「开始聊天」。

## 四、怎么拿一个 API Key

推荐 **DeepSeek**：中文好、便宜、注册简单。

```
① 手机或电脑打开  platform.deepseek.com
② 注册（手机号或邮箱），按提示实名
③ 登录后左侧菜单找到「API keys」
④ 点「创建 API key」，起个名字（随便填）
⑤ 复制显示出来的 sk-xxxxxxxxxxxx
```

> ⚠️ **这串 Key 只显示一次**。关掉页面就再也看不到了，只能重新创建一个。
> 先粘到备忘录里存好。

### 要花多少钱

新用户一般有免费额度，够你先聊一阵。
充值最低 10 元，陪伴场景每轮对话大约几百到一千 token，**10 元通常能撑上千轮**。

### 不想花钱 / 不想注册

| 选择 | 做法 | 代价 |
|---|---|---|
| 智谱 GLM | 选「智谱 GLM」，模型填 `glm-4-flash` | 这个模型免费 |
| 硅基流动 | 选「硅基流动」，部分开源模型免费 | 额度有限 |
| 自己电脑上的 Ollama | 选「电脑上的 Ollama」，地址填电脑 IP | 完全免费、数据不出局域网，但**电脑要开着** |

## 五、日常怎么用

```
打字 → 点右下角 ↑ 发送（或按键盘上的发送键）
说话 → 点左下角 🎙 → 说完自动发送
想改设置 → 点右上角 ⚙
```

设置里能改：

- 换服务商 / 换模型 / 重新填 Key
- 开关自动朗读、调语速音调
- TA 怎么称呼你
- 换个陪伴者 / 换头像
- 清空对话
- 退出登录

**对话会自动记在本机**，关掉再打开还在。
它还会慢慢记住你说过的事（比如你的名字、你的猫、你在忙什么），
每 4 轮整理一次，下次聊天时自然带出来。

## 六、连不上怎么办

对照这张表找你的情况：

| 屏幕上显示 | 意思 | 怎么办 |
|---|---|---|
| API Key 不对或已失效 | Key 复制错了，或已被删除 | 重新复制一次，注意别带空格 |
| 账户余额不足或额度用完了 | 钱用完了 | 去服务商后台充值，或换一家 |
| 请求太频繁被限流了 | 发太快 | 等几秒再发 |
| 模型名不对 | 模型名写错了 | 点「获取列表」选一个 |
| 连不上服务商 | 网络问题 | 换个网络试试；OpenAI 国内通常连不上 |
| 公网地址必须用 https | 地址填成了 http | 公网地址改成 https:// 开头 |
| 手机上用 localhost 连不到电脑 | 填了 127.0.0.1 | 手机上 localhost 指手机自己，要填电脑的局域网 IP |

还是不行的话，最快的判断方法：

> **换一家服务商试试。** 换成智谱（`glm-4-flash`，免费）能通，
> 说明是原来那家的 Key 或余额问题，不是 App 的问题。

## 七、关于隐私（请认真看这一段）

这个 App 能承诺什么、不能承诺什么，说清楚：

### ✅ 能承诺

- **没有"潮汐"的服务器**。对话不经过任何中间方，直接从你手机发给你选的服务商
- **账号、对话、记忆只存在这台手机里**，不上传、不备份到云
- **API Key 加密存储**，用的是安卓系统级的 Keystore。App 界面里只能看到 `sk-a****9f3c` 这样的打码，看不到完整 Key
- **只申请两个权限**：联网（必须）和麦克风（只用于语音输入，拒绝也能打字聊）
- 不申请位置、通讯录、相册、相机、通知

### ⚠️ 不能承诺

- **对话内容会发给你选的那家服务商**，用来生成回复。
  各家怎么处理数据，看各家的隐私政策——这不在潮汐的控制范围内。
- **最私密的选择是自己电脑上跑 Ollama**，那样数据不出你家局域网。
- **危机识别靠关键词**。说得太隐晦可能识别不到。
  如果你或你身边的人正处在危险中，**请直接打 12356**（全国心理援助热线，24 小时，免费）。

### 关于危机干预

说到自伤相关内容时，App 会**不经过模型**，直接给固定回应和热线电话。
这是刻意的设计：这类事不能交给概率性输出。

但它不是医生，不做诊断，不开药，也不替代专业帮助。

## 八、卸载与重装

```
长按桌面图标 → 卸载
```

卸载会**删掉所有数据**：账号、对话、记忆、存的 Key。
想保留的话先别卸。

重装后是全新状态，要从注册开始。

## 九、给开发者的一句话

```
源码：src/app/index.html（页面，唯一源码）
构建：tools\build_apk.ps1
```
