## 1. 这一版和 v5 的根本差别

| | v5（潮汐） | v6（Orbit） |
|---|---|---|
| 谁能用 | 要服务端在公网、要注册、要 Key | 发 APK，装上就能用 |
| 断网 | 退回手机内置模型 | 本来就在手机上 |
| 慢在哪 | 每次换页/发消息先等服务端超时（约 10 s） | 页面切换不等任何网络；回复只等模型 |
| 成本 | 按 token 付费 | 零边际成本 |
| 上限 | 云端大模型 | 1.5B 小模型，靠提示词与规则兜底 |

**为什么接受"模型变小"这个代价**：v5 最大的问题不是模型不够强，是**用户根本走不到模型那一步**。见 ADR-18。

## 4. 关键规则（都能在代码里找到）

### 4.1 对话链路

`send()` 里的顺序是固定的，**每一步都可能直接结束这一轮**：

1. 安全词表命中 → 固定话术 + 热线，**不调模型**，这句及其之前的内容从此不进入模型上下文
2. 问"你是 AI 吗" → 按规则如实回答，不调模型
3. "忘掉我的 X" → 先确认，不静默删除
4. 额度用完 → 一句告别 + 付费墙，不调模型
5. 情绪识别 / 意图识别（只影响回复方式）
6. 记忆候选（每条消息最多 1 个）
7. 记忆召回（低于阈值不召回）
8. 拼提示词 → 流式生成 → 输出守卫 → 必要时重生成 1 次 → 不行就用兜底话术并记一条 `quality_fallback`

### 4.2 提示词的两段式

- **稳定段**（人格、规则、沟通偏好、few-shot）：整个会话不变，留在 KV 缓存里，每条新消息只解码新内容。
- **当轮提示**（关系阶段、上次摘要、情绪策略、意图提示、召回的记忆、是否要提问）：只拼在最新一条用户消息前面，不进缓存、不存储。

设计原因：**任何"稳定段"的改动都会让整段缓存失效**，在模拟器上实测过 594/660 token 重算（约 33 秒）。所以阶段和摘要被移到了当轮提示。详见 `docs/25`。

### 4.3 输出守卫（提示词约束不住的东西）

逐句检查，命中即删这一句：声称有身体/能看见用户、说教句式、未请求的建议（用户没要建议时）、客服腔、暗示替代真人、自行提起自伤、重复上一轮、复读用户原话、多余的问题、问了已经问过的问题、超长。全部句子被删光 → 重生成一次 → 仍不行 → 兜底话术 + 埋点。

### 4.4 记忆

- 写入：只记"明确说过 + 以后有用 + 相对稳定"的；每条都要用户点"记住"（B 组实验会自动保留低敏感偏好，但仍展示、仍可撤销）。
- 敏感：健康、金钱、证件、性取向/信仰/政治——默认既不自动存也不提议。
- 召回：`相关性 × 重要度 × 新鲜度 × 信任`，低于 0.12 不召回，一次最多 2 条；事件类在到期日附近权重最高，过期后为 0。
- 删除：留一个内容为空的墓碑，同一槽位之后不会再被悄悄存回来。

### 4.5 主动互动

6 个条件全满足才发：通知已开、不在免打扰时段、当天额度未满、没有连续被忽略降频、有值得说的具体事、类型未被屏蔽。
候选优先级：到期事件 > 兴趣延续（中/高主动，4 天一次）> 中断对话的接续（间隔 6 小时至 3 天）> 轻互动（仅高主动）。
高主动每天最多 2 条，低/中 1 条。被忽略 3 次 → 降为隔天。

### 4.6 玩法数值

| 项 | 值 |
|---|---|
| 抓娃娃 | 每天 3 局，每局 3 次抓取（玩家 2 次 + 她 1 次）；爪尖离娃娃 ≤40（网格 0–1000）算中；她的第一抓必中，之后 70/30；她抓完即本局结束 |
| 一起专注 | 预设 15/25/45 分钟，可调 10–120；满 10 分钟才记一条；暂停超 30 分钟自动结束 |
| 关系进度 | 抓娃娃 +20、专注 +10，**每天最多 +30**（按"这笔加上去会不会超"判）；同一局只记一次 |
| 邀请 | 每天 1 次、7 天内最多 3 次、22:00–09:00 不发、没有历史绝不发 |

### 4.7 额度与会员

| | 免费 | Premium |

| 记忆容量 | 20 | 200 |

## 7. 风险

| 风险 | 等级 | 对策 / 现状 |
|---|---|---|
| 1.5B 模型理解力不足，回复平淡 | 高 | 提示词分两段 + 大量输出守卫 + 兜底话术；速度与质量都要真机复测 |
| 危机词表漏判换种说法 | 高 | 已知局限；计划加分类层 |
| 用户情感依赖 | 高 | 提示词禁止"你只有我"类话术；输出守卫会删掉这类句子；AI 身份如实回答 |
| APK 951 MB，下载门槛高 | 中 | 目前无解，换更小模型要重新测质量 |
| 模拟器速度不代表手机 | 中 | 上线前必须在真机测 |
| 记忆规则覆盖不全 | 中 | 宁少勿多；用户可见可删 |
