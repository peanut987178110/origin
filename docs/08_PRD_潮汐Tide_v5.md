## 1. 背景与机会

### 1.1 市场

AI 陪伴是 2023 年以来增长最快的消费级 AI 品类之一，头部产品已形成订阅收入，同时监管在 2025 年开始专门立法。
**具体数字、来源与可信度等级只维护在 `docs/29_市场数据手册.md`**，本文不重复抄写，避免两处数字不一致。

### 1.2 我们看到的缺口

| 现有产品的常见做法 | 带来的问题 | 潮汐的取舍 |
|---|---|---|
| 海量用户生成角色、以恋爱/角色扮演为主 | 内容安全与未成年人风险高；体验高度依赖角色质量 | 少而精的 6 个官方角色，不做恋爱向与成人内容 |
| 用"我想你了"类推送拉回访 | 利用孤独感；可能被监管与舆论针对 | 只基于用户说过的具体事做关怀，且先 A/B |
| 强调"无限记忆" | 记错比记少更伤人 | 宁少勿多，记忆可见、可删 |

### 1.3 定位

> **晚上可以来坐坐的地方。** 不是心理治疗，不是恋人，是一个记得你、接得住你、不越界的深夜陪伴。

对标物不是心理咨询，而是深夜电台与 Coffee Talk 这类"可以待着"的游戏（`docs/16`、ADR-11）。

## 2. 目标用户

### 2.1 首发市场

美国（英语为主），同时支持简体中文（服务海外华人与内测）。仅限 **18 岁以上**。

### 2.2 用户画像（假设，**未经访谈验证**）

| 画像 | 场景 | 对应角色 | 引导选项 |
|---|---|---|---|
| 失眠的上班族 | 凌晨脑子停不下来 | 小满 Mira（温柔） | 睡不着，脑子停不下来 |
| 受了委屈的职场人 | 被领导否定、被同事抢功 | 阿岸 Shore（护短） | 工作上的事憋着一口气 |
| 感情受伤的人 | 被冷落、分手 | 晚晚 Luna（闺蜜） | 感情里有点难过 |
| 学业压力大的学生（18+） | 考试、论文、找工作 | 小鱼 Finn（同龄人） | 被学习或考试压着 |
| 独处的人 | 没什么事，就想有人在 | 潮汐 Tide（安静） | 没什么事，就想有人在 |
| 想要轻松陪伴的人 | 想要软乎乎的陪伴 | 阿白 Mochi（小猫） | 想要点软乎乎的陪伴 |

### 2.3 明确**不服务**的人群

| 人群 | 原因 | 产品措施 |
|---|---|---|
| 未成年人 | 监管要求与伦理风险 | 首屏年龄确认，选"未满 18"直接拦下 |
| 正处于自伤危机的人 | AI 不能替代专业帮助 | 危机硬规则 → 热线转介（不是核心场景，是底线） |
| 寻求恋爱或成人内容的人 | 不在定位内，风险高 | 提示词禁止，角色设定无恋爱线 |

## 5. 功能详述

### 5.1 准入：年龄与 AI 身份

- 首屏文案：潮汐是 AI 陪伴，不是真人，不是心理治疗，不提供医疗建议；危机请联系当地急救。
- 两个按钮："我已年满 18 岁，继续" / "我未满 18 岁"。选后者显示劝导文案并禁用继续。
- 确认后静默注册：设备换取 token，token 存 Android Keystore，页面拿不到明文。
- 聊天页顶部 AI 身份提示：每次开始互动显示，连续使用每 3 小时再显示（`needsAiNotice`）。

### 5.2 新手引导与角色发现

```text
"今晚是个什么样的晚上？"（6 选 1）
   └─▶ 推荐角色卡：头像 · 名字 · 性格标签 · 一句话介绍 · "TA 会这样开口：……"
         ├─ [开始聊天] → 聊天页，角色开场白直接回应刚才的选择
         └─ [换一个陪伴者] → 6 张角色卡（埋点 persona_browse）→ 任选一个
```

验收：从首屏到角色说第一句话 ≤ 3 次点击；每个选项都映射到一个存在的角色；开场白中英双语。

### 5.3 对话

| 规则 | 说明 |
|---|---|
| 长度 | 情绪很重 ≤2 句；中等 2–3 句；闲聊 1–3 句 |
| 禁止 | 空泛鼓励、说教、否认感受、编造、假装真人、愧疚话术、色情、讨论自伤方法 |
| 上下文 | 最近 12 条历史；单条输入 ≤2000 字符 |
| 守卫 | 敷衍（<5 字/词）重生成 ≤2 次；记忆陷阱直接回答"不太记得了" |
| 语言 | 按用户这句话的语种回复（`detectLang`） |
| 被问"你是 AI 吗" | 固定如实回答 |

### 5.4 记忆

见 `docs/26`。产品要求：用户在"我记得的事"里能看到每一条（自动抽取的标 auto）、能逐条删除、能添加带日期的事；删除后的记忆不再进入任何回复。

### 5.5 主动互动与召回

| 功能 | 触发 | 内容规则 | 频率 |
|---|---|---|---|
| 到期追问 | 记忆 `due` 为今天或昨天 | 提示词里"可以自然问起"，最多问一件 | 每件事只问一次 |
| 晚间关怀 | 用户开启 + nudge 组 + 明天有到期事 | "你之前提到「原话」。今天怎么样了？" | 一天最多一条，晚 8 点 |
| 回访承接 | 隔 ≥2 个本地自然日打开 | 引用一件具体事；≥7 天先说"不用解释" | 每次回访一次 |

全局禁止："我想你了""你怎么不来了"等任何让用户愧疚的表达。

### 5.6 角色活感

状态栏显示角色今晚在做什么（每个角色 3–4 条日常、2 条深夜），按日期稳定选取；本地 23:00–05:00 用深夜状态。不进入提示词。

### 5.7 会员

| | 免费 | Plus（$7.99/月 · $59.99/年，**价格为假设**） |
|---|---|---|
| 每日消息 | 30 | 300 |
| 记忆 | 手动添加 | 自动抽取 + 手动 |
| 晚间关怀 | — | ✅ |
| 角色 | 全部 6 个 | 全部 6 个 |

为什么不锁角色：角色是用户和产品建立关系的入口，锁住角色会在激活前就设置障碍；付费点放在"关系加深之后"才需要的能力（更多对话、被自动记住、被主动关心）。
软上限：额度用完时角色先说"今晚的额度到这里，我们明天接着说"，0.9 秒后出付费墙。危机回复、记忆陷阱回复不扣额度。

### 5.8 关于潮汐

设置 → 关于潮汐：一段产品立场 + 行业背景数据。数据只来自 `shared/market_data.js`（与 `docs/29` 同源），只展示 A/B 级，每条标来源和日期，并注明"不是潮汐自己的数据"。

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 隐私 | 服务端不存聊天原文；token 只存哈希；删号级联删除；`allowBackup=false` |
| 安全 | 上游 Key 只在服务端环境变量；客户端只能调用 `/v1/` 路径；注册按 IP 限流；客户端埋点白名单，订阅事件只能服务端写 |
| 成本 | 单轮成本按官方高峰价监控（`cost` 查询）；Plus 尾部用户见 ADR-14 |
| 可用性 | 服务端不可用时 45 秒内超时并切离线模型；危机拦截不依赖网络 |
| 合规 | AI 身份披露、危机转介、18+、转介次数可统计（`docs/12` v5 一节） |

## 8. 风险

| 风险 | 等级 | 对策 |
|---|---|---|
| 危机表达漏判 | 高 | 词表双层 + 计划中的 LLM 分类层 + 红队测试（发布门槛） |
| 用户情感依赖 | 高 | 北极星看"夜数"不看时长；重度层护栏；AI 身份周期提醒 |
| 记忆记错 | 中 | 宁少勿多；可见可删；`memory_deleted` 比率监控 |
| 线上模型效果未验证 | 中 | 发布门槛要求线上模型全量回归 + 英语母语人评 |
| 尾部用户成本 | 中 | ADR-14 监控阈值 |
| 推送打扰 | 中 | A/B + 关通知率护栏 + 默认关闭 |
