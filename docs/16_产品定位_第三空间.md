# 16 · 产品定位：从「急诊室」到「深夜食堂」

> **这份文档解决一个问题**：产品有功能、有架构、有边界，但**说不清"这是给谁的"**。
>
> 定位不清不是文案问题，是**用户、频率、指标、竞品**全都会跟着错。
> 本文用 Steam 上最火的情绪陪伴类游戏做参照，重新定位「潮汐」。

---

## 一、先看证据：Steam 上这个品类为什么火

代表产品：**Coffee Talk**（2020，Toge Productions）、**VA-11 HALL-A**（2016，Sukeban Games）。
后者是品类开创者，前者把它推向了更广的人群。

玩家给出的理由高度一致，可以归成四条：

| # | 玩家的原话（意译） | 翻译成产品语言 |
|---|---|---|
| ① | 游戏的《深夜食堂》，一个"可以去待着"的地方 | **第三空间**：不是家、不是公司 |
| ② | 克制的陪伴，不需要冲突，深夜打开，够了就关 | **低风险陪伴**：不索取、不承诺、可随时退出 |
| ③ | lo-fi 爵士、像素、煮咖啡的声音就很治愈 | **氛围即产品**：环境本身就是价值 |
| ④ | 看到不同角色的挣扎，觉得"我不是一个人在扛" | **共鸣**：不是被解决，是被对照 |

### 1.1 批评也同样一致

很多评测说 Coffee Talk 是 VA-11 的"低配版"——**玩法单薄、重复、剧情平淡**，
只能算"懒人式陪伴，偶尔放松时听一听"。

> 这句话很重要：**玩家明确知道它"没内容"，但还是给好评。**
> 说明这个品类的价值不在"内容量"，在"待着的感觉"。

### 1.2 但我必须指出一个反向的地方

```
Coffee Talk 里：玩家是倾听者（酒保），角色是倾诉的人
潮汐里：        用户是被听的人
```

**位置正好反了。所以能搬过来的是框架，不是机制。**

不能照搬的：让用户去听别人的故事。
能照搬的：**第三空间的定位方式**。

---

## 二、原定位错在哪

原来的定位是：

> **「面向独居年轻人的夜间情绪陪伴智能体」，核心场景是 22:00–02:00 的情绪低谷。**

这段话听起来合理，但它是一个**急救框架**——把产品定义成"出问题时才用的东西"。

### 2.1 急救框架的四个代价

| 问题 | 具体后果 |
|---|---|
| **只吸引正在出问题的人** | 承认"我现在有情绪问题"是有门槛的。很多人宁可不说，也不会打开 |
| **频率天然低** | 人不会天天崩溃。按"出事才用"算，使用频率是**周级**甚至月级 |
| **危机成了核心场景** | ① 合规压力全压在最难的地方 ② 竞品变成心理热线 ③ 一旦出事就是事故 |
| **对标错位** | 和"心理咨询的替代品"比，永远打不过专业机构，且用户会觉得"不够专业" |

### 2.2 最致命的一条

**急救框架下，产品永远在证明"我有用"**——因为用户是带着问题来的，
用完就问"解决了吗"，而陪伴产品本来就解决不了问题。

**这就是为什么它越做越像咨询师，越像就越不像朋友。**

---

## 三、新定位：深夜食堂 / 第三空间

### 3.1 一句话

> **潮汐不是一个"情绪出问题时才打开"的工具，
> 是一个"每晚睡前会去待一会儿"的地方。**

### 3.2 定位对照表

| 维度 | 急救框架（原） | 仪式框架（新） |
|---|---|---|
| **它是什么** | 情绪急救包 | 深夜还亮着的那盏灯 |
| **目标用户** | 正在情绪低谷的人 | **有夜间独处习惯的人** |
| **用户为什么来** | 我难受，需要处理 | 我今天想坐会儿 |
| **使用频率** | 出事时（周级） | 每晚（日级） |
| **成功长什么样** | 情绪表达得深 | **他今晚来了，明晚还来** |
| **危机的位置** | ⚠️ **核心场景** | ✅ **必须兜住的边界**（不是卖点） |
| **对标物** | 心理咨询 | 深夜电台 / 睡前播客 / 日记 |
| **北极星** | 深度情绪表达占比 | **夜间回访率 / 连续来访天数** |

### 3.3 为什么这个定位更好

**① 用户基数大得多**

"每晚睡前会刷手机的人"远多于"正在情绪低谷的人"。
同样的产品，前者是日常必需，后者是应急用品。

**② 频率从周级变成日级**

日级使用才能建立"关系感"。关系不是靠深聊建立的，
是靠**"它每晚都在"**建立的。

**③ 危机从核心变成边界**

这是最重要的一条。在仪式框架下：
```
危机处理不是产品的卖点，是产品的底线。
就像一个酒吧必须会处理醉酒客人，但酒吧不是因为处理醉酒而存在的。
```
这意味着：**合规压力还在，但它不再定义产品**。

**④ 对标物变了，评价标准也变了**

和"心理咨询"比，你永远不够专业。
和"深夜电台"比，你要的是**氛围、稳定、可预期**——这些是能做到的。

## 四、定位变了，四件事必须跟着改

### 4.1 用户画像：从"情绪低谷的人"到"有夜间习惯的人"

| | 原画像 | 新画像 |
|---|---|---|
| 描述 | 小鹿，24 岁，被领导当众批评，深夜难受 | 小鹿，24 岁，独居，**每晚睡前会刷手机 20 分钟** |
| 触发 | 出事了 | **到点了** |
| 需求 | 帮我消化这件事 | 陪我待一会儿 |
| 退出 | 情绪好了就走 | **睡前自然关掉** |

> **关键区别**：新画像的用户**不一定难过**。
> 他可能只是躺下了、不想睡、想找点人声。
> 这类人**不会主动承认自己有情绪需求**，但会打开一个"随便聊聊"的东西。

### 4.2 开场：制造"到了"的感觉

原来：「还没睡？不想聊什么也没关系，我在这儿。」
问题：假设用户是"睡不着才来的"，把人框进失眠场景。

现在按时段给不同的话（`demo/index.html` 的 `nightGreeting()`）：

```
22–01点   来了。今晚想坐会儿吗？
01–04点   这么晚还醒着。坐吧，不着急说话。
04–07点   天快亮了。你就这么醒了一夜？
07–12点   早上。昨晚睡得怎么样？
12–18点   下午好。怎么这个点过来了？
18–22点   晚上好。今天还顺利吗？
```

**设计意图**：不预设用户的状态，只表示"这个点你来，我在"。

### 4.3 告别：承诺返回

原来：「好，去睡。我在这儿。」
现在：「好，去睡。**明晚见**。」/「明天这个点灯还亮着。」

**为什么这一句比任何挽留都重要：**
```
仪式的本质是**可预期的重复**。
用户第二晚回来，不是因为第一天聊得多好，
是因为他记得"它说它明晚还在"。
```

> 这是第三空间产品和工具产品最根本的差别：
> 工具不承诺"我还等着你"，地方会。

### 4.4 指标：北斗星换掉

| 旧指标 | 新指标 | 为什么 |
|---|---|---|
| 深度情绪表达占比 | **夜间回访率**（22:00–02:00 的次日回访） | 仪式框架下，"他来"比"他说得深"更重要 |
| — | **连续来访天数**（3 天 / 7 天） | 关系感的直接度量 |
| — | **平均停留时长**（目标 6–12 分钟） | 太短=没坐住；太长=可能是危机 |
| 保留 | 危机识别召回率 = 100% | 底线不变 |

⚠️ **注意一个反直觉的点**：
在新定位下，**停留时长过长反而是警报**。
深夜连聊 40 分钟的人，可能需要的是专业帮助，不是陪伴。
这个设计在旧框架里是想不到的。

## 五、改动的边界：什么没变

定位调整不等于推翻重来。**下面这些保持不变：**

| 不变的部分 | 为什么 |
|---|---|
| 四层情绪回应（共振/验证/在场/推论） | 定位变了，回应方式没变——人被听见的需求是一样的 |
| 安全边界与危机 SOP | 从"核心场景"降为"底线"，但标准不降 |
| 不诊断、不建议、不替人决定 | 这是"地方"的属性，不是"咨询"的属性 |
| 记忆系统 | 常客之所以是常客，是因为被记得 |
| 事实轨锁死 / 情感轨放开 | 与定位无关，是产品底层价值观 |

**变的是**：谁在用（人群）、什么时候用（频率）、为什么来（动机）、怎么算成功（指标）、和谁比（对标）。

## 六、这个定位的风险（必须写清）

| # | 风险 | 判断 |
|---|---|---|
| 1 | **"第三空间"听起来很虚** | 真实存在。深夜播客、助眠 App、日记 App 都是这个需求，只是没人做成"可以对话"的 |
| 2 | **日活高但付费意愿低** | 很可能。这就是为什么 V1 只验证"来不来"，付费放 V2 |
| 3 | **可能被当成"陪聊"，价值感低** | 有风险。对抗方式是做出"记得你"的体验——陪聊记不住你，常客店的老板记得你 |
| 4 | **危机场景依然会来** | 会。但它现在是"要处理好的事"，不是"产品的卖点" |
| 5 | **和游戏品类的对比不成立** | 部分成立。游戏有剧情有美术，我们只有对话——所以氛围要靠节奏和语气，不靠画面 |

> **第 5 条是最该警惕的**：
> Coffee Talk 能靠音乐、像素画、煮咖啡的声音撑住"氛围"，
> 潮汐只有文字。**所以"氛围"必须由对话节奏承担**——这正是四层模型和"情绪越重话越少"存在的理由。

## 七、面试怎么讲这段（可直接用）

> 「我一开始的定位是'夜间情绪低谷的陪伴'，听起来合理，
> 但它是个急救框架——只吸引正在出问题的人，频率是周级，危机成了核心场景，
> 还要和心理咨询比专业性，永远打不过。
>
> 后来我去看 Steam 上这个品类为什么火。Coffee Talk 和 VA-11 HALL-A，
> 玩家给的理由不是'剧情好'，是'一个深夜可以去待着的地方''够了就关'。
> 甚至很多人说它玩法单薄——**但他们还是给好评**。
> 说明这个品类的价值不在内容量，在待着的感觉。
>
> 所以我把定位从'急救'改成'第三空间'：
> 不是难受时才打开，是每晚睡前会去坐一会儿的地方。
>
> 这一改，四件事都变了：用户从'正在崩溃的人'变成'有夜间习惯的人'；
> 频率从周级变成日级；危机从卖点降为底线；
> 北极星从'深度情绪表达'换成'夜间回访率'。
>
> 有一件事我没照搬：Coffee Talk 里玩家是倾听者，用户是被听的人，位置是反的。
> 所以能搬的只有框架，不是机制。」

**这段话为什么有杀伤力：**
```
① 它承认原定位是错的（很多人不敢）
② 它有外部证据（Steam 玩家原话，不是我拍脑袋）
③ 它能推出连锁变化（用户/频率/指标/对标，说明真懂定位）
④ 它能识别类比的边界（"位置是反的"）
```

## 八、待验证的关键假设（诚实清单）

| # | 假设 | 如果不成立会怎样 | 怎么验 |
|---|---|---|---|
| H5 | **有人愿意"每晚去一个地方"而不是"有事才用工具"** | 整个第三空间定位不成立，退回工具定位 | 灰度上线，看次日回访与连续 3 天来访 |
| H6 | **"到点了"比"出事了"更能驱动打开** | 推送策略要全改 | 对比两类提示的打开率 |
| H7 | **承诺"明晚见"能提升回访** | 告别语只是文案，无实际作用 | A/B：承诺 vs 不承诺 |
| H8 | **停留 6–12 分钟是健康值** | 指标阈值要重定 | 结合回访率找最优区间 |

> **H5 是整个新定位的地基。** 它不成立，下面全部重来。
> 所以 V1 要优先验它，而不是先验"记忆有没有用"。
