# 11 · 用户访谈与需求验证

> `docs/01` §6.2 列了 4 条关键假设（H1–H4），但全部标着"待验证"，
> 而验证方式写的是"埋点看数据"——问题是**产品还没上线，没有埋点**。
>
> 这份文档补上上线前唯一的验证手段：**找人聊**。
>
> ⚠️ 现状：**本项目尚未做任何用户访谈。**下面是可直接执行的方案，做完把结果填进 §五。

---

## 一、为什么"我自己就是目标用户"不成立

你可能就是 24 岁一线城市独居青年。这反而更危险：

| 你的直觉 | 真实情况 |
|---|---|
| "我深夜确实想找人说话" | 你可能只是**想要一个听众**，而不是"想用 AI" |
| "朋友劝我我会烦" | 你烦的是**那个朋友**，不是"被劝"这件事 |
| "有记忆会很有感觉" | 你还没体验过**记错了**是什么感觉 |

> **创始人型产品经理最大的陷阱，是把自己的偏好当成市场需求。**
> 你做的是"你觉得好"的产品，用户要的是"能解决我问题"的产品。
> 这两者很多时候不重合。

**访谈不是为了证明你对，是为了尽快发现自己错在哪。**

## 二、访谈设计

### 2.1 目标与样本

| 项 | 内容 |
|---|---|
| **要验证的假设** | 见 §三（H1–H4） |
| **样本量** | **最少 8 人，目标 12 人** |
| **注意** | 8 人是"能听出模式"的下限，不是"能得出结论"的样本量。这是定性研究，不是定量 |
| **招募渠道** | 朋友圈 / 小红书私信 / 同事 / 豆瓣小组 / 学校群 |
| **筛选条件** | 18–28 岁；一二线城市；独居或合租；近一个月有过"深夜情绪低落" |
| **排除** | 你自己、你的直系朋友（会顾忌你面子）、做 AI 行业的人（会跟你聊技术） |

> **为什么排除朋友**：朋友会说"这个想法很好啊"。
> 你要的不是鼓励，是**真话**。

### 2.2 访谈原则（比问题清单更重要）

```
✅ 问过去的行为，不问未来的意愿
   ❌ "你会用这样的产品吗？"（人会为了礼貌说会）
   ✅ "上一次你深夜睡不着、心里堵得慌，是什么时候？当时你做了什么？"

✅ 问具体的一次，不问一般情况下
   ❌ "你平时会找朋友倾诉吗？"
   ✅ "最近一次你跟朋友说'我很难受'是什么时候？说了之后对方怎么回的？"

✅ 沉默是可以的
   用户沉默的时候，往往在回忆真实场景，别急着接话

✅ 不介绍你的产品（前 30 分钟绝对不提）
   一旦介绍了，后面所有回答都会被污染
```

> 🔑 **最重要的一条**：《The Mom Test》的核心——
> **不要问"你觉得这个 idea 怎么样"，要问"你现在是怎么解决这个问题的"。**

## 三、四个假设怎么验（一假设一方法）

### H1 · 用户愿意向 AI 倾诉真实情绪

| 项 | 内容 |
|---|---|
| **为什么重要** | 不成立 = 产品没有存在的理由 |
| **访谈怎么验** | 问："你有没有跟 AI 聊过自己的事？聊到什么程度？哪些话你没说？为什么没说？" |
| **关键信号** | ✅ 能说出具体的、**说出来会有点羞耻**的事（"我跟我妈吵架了""我怀疑我不行"）<br>❌ 只说"问过它问题""让它改过文案"——那是工具用法，不是倾诉 |
| **反例信号** | 说"AI 又不是人，跟它说有什么用"——这是**最强的反对信号**，必须认真对待 |
| **上线后怎么验** | 深度情绪表达占比 ≥ 20%（含负面情绪词且长度 > 30 字的会话） |

**访谈时真正要挖的：**
> 用户跟 AI 说过真话吗？如果说过，是什么让他们愿意？
> 如果没说，是什么让他们不愿意？——**后一个问题比前一个值钱十倍。**

---

### H2 · "记忆感"能显著提升留存

| 项 | 内容 |
|---|---|
| **为什么重要** | 记忆是整个产品的核心差异化，也是成本大头 |
| **访谈怎么验** | 这个假设**访谈验不出来**（用户无法想象没用过的东西）。替代方案见下 |
| **替代方案** | **假门测试（Fake Door）**：在 Demo 里做两个版本——A 有记忆、B 无记忆，找 5 个人各聊 15 分钟，第三天再问"你还想找它聊吗？想聊什么？" |
| **关键信号** | 有记忆组的人第三天主动提起"上次那个事"，无记忆组的人在重新自我介绍 |
| **判定标准** | 有记忆组的回访意愿明显更高 → 值得投 |
| **上线后怎么验** | A/B：有记忆 vs 无记忆，看 7 日留存差 ≥ 8pt |

> 💡 **面试价值**：这个"假门测试"是很强的素材。
> 「我没有上线数据，但我用 Demo 做了个对照实验——
> 5 个人，两组，第三天回访。有记忆组的 3 个人里有 2 个主动问我'上次那事它还记得吗'。
> 样本很小，不能当结论，但它让我相信值得在记忆上投资源。」

---

### H3 · "无评判"比"给建议"更受欢迎

| 项 | 内容 |
|---|---|
| **为什么重要** | 这直接决定人格设计（不给建议 vs 给建议） |
| **访谈怎么验** | 问："你跟朋友说完难受的事，对方哪种反应让你最舒服？哪种让你不想再说？" |
| **要挖的细节** | 让对方**举例**。抽象回答"我喜欢被理解"没有信息量 |
| **关键信号** | 高频出现"别想太多""你要这样想""我早就跟你说了"——这些是**被讨厌的建议** |
| **反面信号** | 也有人说"我希望有人给我出主意"——**这说明人群里有分化**，要记下来 |
| **上线后怎么验** | A/B：共情优先 vs 建议优先，看轮次与好评率 |

**如果出现分化，这是最有价值的发现：**
> 一部分人要"被听见"，一部分人要"被帮到"。
> 那产品可能要**先判断诉求类型再决定回法**——
> 这正好对应 `prompts/03` 的意图识别节点。
> **访谈能直接改动你的产品结构，这才叫有效访谈。**

---

### H4 · 夜间是核心时段

| 项 | 内容 |
|---|---|
| **为什么重要** | 决定运营投放时间、推送策略、服务器资源 |
| **访谈怎么验** | 问："你最近一次特别想找人说话是几点？当时在做什么？" |
| **关键信号** | 具体到时段："十一二点""躺床上之后""关了灯" |
| **反面信号** | 集中在通勤/午休——**那产品定位要改**，不是夜间陪伴，是碎片陪伴 |
| **上线后怎么验** | 时段分布，22:00–02:00 占比 ≥ 40% |

## 四、访谈提纲（可直接照着问）

> **30 分钟版**。前 25 分钟绝不提产品。

### 开场（2 分钟）
```
"我在研究年轻人深夜的情绪状态，想听听真实经历，不是推销任何东西。
 没有对错，你怎么想就怎么说。可以录音吗？只用于我自己整理。"
```

### 第一段：还原一个真实场景（10 分钟）
```
1. 最近一个月，有没有哪个晚上你心里特别堵？
2. 那天大概几点？你在哪？在做什么？
3. 那时候你最想做什么？实际做了什么？
4. 有没有想找人说？找了谁？还是没找？
   → 如果找了：说了什么？对方怎么回的？你当时什么感觉？
   → 如果没找：为什么没找？（← 这里要追问三层）
5. 后来那晚怎么过去的？
```

### 第二段：验证"为什么不找真人"（8 分钟）
```
6. 你会不会发那种"仅自己可见"的朋友圈，或者发完就删？
   → 如果有：当时为什么这样？
7. 如果有个东西随时能说话、不会评判你、还记着你之前说过的话——
   你觉得跟它说和跟朋友说，会有什么不一样？
   （← 注意：这是假设性问题，可信度打折，但能听到顾虑）
8. 你用过 AI 聊天类的产品吗？聊到什么程度？哪句话你没跟它说？
```

### 第三段：反向验证（5 分钟）
```
9. 有什么情况下你绝对不会用它？
10. 如果它哪天说错话、或者显得很假，你还会用吗？
```

> **第 9、10 题是整份提纲里最重要的两题。**
> 因为所有人都会告诉你"这个想法不错"，但只有这两题能问出真实顾虑。

### 收尾（5 分钟）
```
11. 你身边有没有类似情况的朋友？能介绍我聊聊吗？
    （← 滚雪球招募，比公开招募质量高）
12. 如果做出来了，愿意试用一下吗？
    （← 愿意 = 一个人情；不愿意 = 一个信号，都记下来）
```

## 七、面试怎么讲这段（模板）

```
"我没有线上数据，所以上线前我做了 8 个用户的深访。
 有三个发现：
 ① 所有人都说'想法不错'，但真正说过'我可能会用'的只有 X 个——
    这说明兴趣和需求是两回事。
 ② 最反直觉的一点：我最担心的'用户觉得跟 AI 说很怪'，
    实际只有 X 个人提到；反而是'它记错了我的事怎么办'被提到 X 次。
    这直接让我把'不编造记忆'放成了一票否决项。
 ③ 有 X 个人明确说希望'被出主意'，这跟我的'不给建议'设定冲突。
    所以我在意图识别里加了'求建议'这个标签，让它在那种情况下可以给建议。
 这个项目最大的改变来自访谈，而不是来自我自己的判断。"
```

> 这段话里有：样本量、反直觉发现、**因访谈而改的产品决策**。
> 比任何"我做了一个完整项目"都有说服力。
