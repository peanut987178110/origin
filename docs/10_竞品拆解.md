# 10 · 竞品拆解

> `docs/02` §2.3 只有一张 6 行的扫描表，说要"3 个竞品各写 800 字"，实际没有。
> 这份文档补上，并且给出**可执行的拆解方法**——因为面试官更在意你怎么看，而不是你看了多少。
>
> ⚠️ **诚实声明**：下面是基于公开资料与产品形态的**结构性拆解**。
> 标 🔬 的地方需要你**亲自注册实跑**后填写。面试时只能讲 🔬 填完的部分。

---

## 一、先讲方法：竞品拆解拆什么

大多数人做竞品分析 = 抄一遍功能介绍。没有价值。
真正有信息量的拆解，只回答三个问题：

```
① 它替用户做了什么取舍？      —— 取舍点就是它的定位
② 它在哪里流失用户？          —— 差评里藏着你的机会
③ 如果我要赢它，从哪一点切入？ —— 结论必须能落到产品决策
```

**四个必拆维度：**

| 维度 | 看什么 | 为什么重要 |
|---|---|---|
| **定位** | 它自称什么，用户实际拿它干什么 | 定位会影响所有后续设计 |
| **核心链路** | 用户从打开到"有感觉"要几步 | 决定留存的第一道门槛 |
| **记忆机制** | 记什么、记多久、怎么用 | 陪伴产品最关键的分水岭 |
| **商业模式** | 怎么收费、免费层卡在哪 | 决定它的付费墙就是你的机会 |

## 二、四个竞品拆解

### 2.1 星野（MiniMax）

| 维度 | 内容 |
|---|---|
| **定位** | AI 虚拟角色社区。核心不是"陪聊"，是"造角色 + 看别人造的角色" |
| **核心链路** | 选角色 / 造角色 → 聊天 → 分享对话截图 → 吸引新用户造新角色 |
| **记忆机制** 🔬 | 公开信息显示有角色设定与剧情延续，长程个人记忆的深度需实测 |
| **商业模式** 🔬 | 订阅 + 虚拟道具类。具体卡点需实测 |
| **强在哪** | **UGC 飞轮**：角色越多，内容越多，获客越便宜。这是它最可怕的地方 |
| **弱在哪** | 角色扮演的框架天然限制"真实关系"——用户知道自己在跟一个**设定**聊天，情绪深度有天花板 |
| **对「潮汐」的启示** | **不要和它比角色丰富度**。它做"扮演"，你做"被记得"——这是完全不同的价值 |

**如果我是它的 PM，我会担心什么：**
> UGC 越繁荣，平台治理成本越高（违规角色、擦边内容），而治理成本会挤压产品迭代。
> 这是一个结构性的负担，也是新玩家切入的窗口。

### 2.2 Character.ai

| 维度 | 内容 |
|---|---|
| **定位** | 通用角色聊天平台，全球最大的 UGC 角色社区 |
| **核心链路** | 搜索/创建角色 → 即时开聊 → 社区分享 |
| **记忆机制** 🔬 | 有角色级记忆，个人级长期记忆的完备度需实测 |
| **商业模式** 🔬 | 订阅制（c.ai+）。具体权益需实测 |
| **强在哪** | 模型能力 + 角色生态 + 先发优势 |
| **弱在哪** | ① 中文语境弱（本地化劣势）② 国内不可直接使用 ③ 通用平台 = 每个垂直场景都不够深 |
| **对「潮汐」的启示** | **通用平台的弱点在垂直深度**。它不会为一个"深夜睡前待一会儿"的场景，单独设计开场、节奏和告别 |

**关键判断：**
> Character.ai 的存在恰好证明了一件事——**角色扮演是已经被满足的需求**。
> 在一个已被充分满足的赛道里做第 100 个角色平台，是没有意义的。
> 但"连续的、被记得的、不扮演的关系"还没有人做透。

### 2.3 Pi（Inflection）

| 维度 | 内容 |
|---|---|
| **定位** | 情感支持型助手。**这是和「潮汐」最像的一个**，必须重点研究 |
| **核心链路** | 直接开聊 → 主动追问 → 语音对话 |
| **记忆机制** 🔬 | 公开信息显示强调"记得你"，具体颗粒度需实测 |
| **商业模式** 🔬 | 免费为主 |
| **强在哪** | ① **语音体验**是行业标杆 ② 对话节奏设计极好——"会等"，不抢话 ③ 共情语料打磨精细 |
| **弱在哪** | ① 中文支持弱 ② 长期记忆的深度不明 ③ 没有针对"夜间场景"做专门设计 |
| **对「潮汐」的启示** | **Pi 证明了"纯共情、不给建议"这条路走得通**，这是最重要的信息 |

**为什么 Pi 是最该抄的作业，也是最该避开的对手：**
> 抄它的是**对话节奏**——它证明了"少说、会等、一次只问一个"是有效的。
> 避开它的是**语音**——V1 不做（见 `docs/09` ADR-01）。
> 但必须承认：**如果 Pi 做了高质量中文版，我的差异化会立刻变薄。**

---

### 2.4 Replika

| 维度 | 内容 |
|---|---|
| **定位** | AI 伴侣（关系型），强调"陪伴关系会成长" |
| **核心链路** | 创建伴侣形象 → 日常对话 → 关系等级成长 |
| **记忆机制** 🔬 | 有长期关系记忆 |
| **商业模式** 🔬 | 订阅制，免费层限制情感深度功能（这是它最大的争议点） |
| **强在哪** | **关系成长感**做得最成熟——用户能感知"它越来越懂我" |
| **弱在哪** | ① 付费墙卡在"情感深度"上，曾被大量用户批评"情感勒索" ② 形象固定，偏情侣向，不适合"搭子"定位 |
| **对「潮汐」的启示** | **付费墙的教训极其重要**：把"关系深度"当付费点，会激怒用户 |

**这条教训直接改了我的定价设计：**
> Replika 的争议在于：用户建立了情感依赖后，才发现"更深的对话"要付费。
> 这被感知为"利用感情赚钱"。
> 所以我的付费墙设计是**卡功能，不卡关系**——
> 免费层也能完整倾诉、也能被记住（30 天），
> 付费买的是"记忆不丢失 + 语音 + 更长记忆"，
> 换句话说是**买资产，不是买感情**。（见 `docs/07` §2.2 第 3 条）

## 三、对比矩阵（面试可直接展示）

| 维度 | 星野 | Character.ai | Pi | Replika | **潮汐** |
|---|---|---|---|---|---|
| 核心价值 | 扮演角色 | 角色生态 | 情感支持 | 陪伴关系 | **被记得的搭子** |
| 记忆深度 | 中 | 中 | 中 | 高 | **高（核心）** |
| 是否扮演 | 是 | 是 | 否 | 部分 | **否** |
| 语音 | 部分 | 部分 | **强** | 部分 | 否（V1） |
| 中文质量 | **强** | 弱 | 弱 | 中 | **强** |
| 夜间场景优化 | 无 | 无 | 无 | 无 | **有** |
| 付费点 | 订阅/道具 | 订阅 | 免费 | 订阅（卡深度） | **订阅（卡资产）** |
| 主要风险 | 治理成本 | 合规 | 中文本地化 | 情感争议 | 留存 |

## 四、结论：我的切入点和它的脆弱性

### 4.1 三个差异化点（按可信度排序）

| # | 差异化 | 可信度 | 为什么 |
|---|---|---|---|
| 1 | **不做扮演，做真实陪伴** | 高 | 角色赛道已满，且扮演天然限制情绪深度 |
| 2 | **夜间场景专门优化** | 中 | 竞品都没做，但**用户是否为此付费待验证** |
| 3 | **中文语境的真实感** | 高 | 海外产品本地化弱，这是结构性窗口 |

### 4.2 但必须诚实面对的三件事

```
① 我的差异化里，"不做扮演"这一条，大厂想抄一周就能抄
② "夜间场景优化"听起来好，但可能只是伪需求——用户未必在意
③ 真正的壁垒只有记忆资产，而它需要时间积累，我没有任何存量
```

> 💡 **面试时讲这段最有杀伤力**：
> 「我做竞品拆解得出的最重要结论，不是'我的差异化在哪'，
> 而是'**我的差异化里有两个可以被一周抄走，剩下那个需要时间但我没有存量**'。
> 所以我判断这个产品在单点上是防守不住的——
> 它真正的机会不在产品本身，在于**大厂不会为了一个低付费意愿的人群做专门的夜间链路**。
> 这是一个'市场结构给我的机会'，不是我产品能力的功劳。」

> **这段话为什么强**：它显示你不是在吹项目，而是在**冷静评估它的生存概率**。
> 面试官听到这种表达，会认为你有真实的产品判断力。

## 五【待你完成】实跑清单

面试前必须完成的动作，做完把 🔬 的格子填掉：

| # | 动作 | 产出 |
|---|---|---|
| 1 | 注册星野，聊 20 轮，测试它是否记得第 3 轮说的事 | 记忆深度结论 |
| 2 | 注册 Pi（如可访问），测语音延迟与节奏 | 语音体验结论 |
| 3 | 看三个产品应用商店的**一星差评**，各取 20 条做归类 | 流失原因表 |
| 4 | 各截 3 张付费页 | 付费墙对比 |
| 5 | 记录你**第一次感到"它懂我"**是在第几轮 | 关键体验时刻 |

> **第 3 条最重要**：差评是唯一免费的、真实的、带情绪的用户研究。
> 因为好评说的是产品想让你看到的，差评说的是产品真正的问题。
