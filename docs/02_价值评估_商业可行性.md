## 1. 产品的四个层次（课程核心模型）

课程用「AI 问书」这个案例讲了产品的层次，这个框架**可以直接套用到任何 AI 产品**：

```
        ▲ 价值层：商业逻辑
        │   → 谁付钱？为什么付？能不能持续？
        │
        │ 深化层：场景细节
        │   → 具体到"晚上 11 点躺在床上说睡不着"这种颗粒度了吗？
        │
        │ 需求层：用户价值
        │   → 用户得到了什么？情绪价值？效率提升？
        │
        │ 基础层：实现
            → 技术上能不能做？成本多少？
```

**把这四层套到「潮汐」：**

| 层次 | 内容 | 自检问题 |
|---|---|---|
| **基础：实现** | 大模型 API + 工作流 + 记忆库 + 前端页面 | 一个人两周能不能做出 Demo？→ 能 |
| **需求：用户价值** | 被听见、被记得、不被评判 | 用户愿意为"被记得"付费吗？→ 待验证（H2） |
| **深化：场景细节** | 深夜失眠、被否定后的自我怀疑、失恋后的空虚 | 提示词写到这个场景了吗？→ 见 `docs/03` |
| **价值：商业逻辑** | 订阅制 + 情绪增值服务 | LTV > CAC 吗？→ 见下方测算 |

> ⚠️ **小白最容易犯的错**：只在"基础层"和"需求层"打转，
> 从不认真回答"价值层"。**面试时你必须能讲清商业逻辑。**

## 2. 市场价值评估

### 2.1 需求底盘（可直接复述的数据）

```
① 中国单身人口 2.4–2.6 亿，占成年人口近 1/4
② 老龄化即将到来 → 银发陪伴需求将爆发
③ 温饱满足后，情绪情感需求必然抬头（马斯洛需求层次）
④ 情绪付费已成为普遍意愿
⑤ 陪伴需求长期未被充分满足

→ 结论：需求池极大、粘性极高
```

### 2.2 TAM / SAM / SOM 粗算（练习用，面试能说出思路即可）

> **2026-11-17 口径修正**：v3/v5 时期这套粗算按中国市场做。v6 是**海外市场**（首发美国），
> 所以下面同时给了两版口径：**现行（海外）** 与 **历史（国内，仅作方法论示例）**。

**现行（海外，首发美国）**

| 层级 | 口径 | 估算 |
|---|---|---|
| **TAM**（总市场） | 英语市场里有情绪陪伴 / 睡前陪伴需求的成年人（18+） | 量级在**亿级**，但这类总数没有可靠口径，只作数量级判断 |
| **SAM**（可服务） | 有睡前独处习惯、愿意为情绪类 App 小额订阅的人 | 无可靠第三方数据，**这个数我不编** |
| **SOM**（可获得） | 首年靠自然增长 + 内容获客的渗透 | 上线前不设目标值（没有基线就定目标等于编数字） |

**历史（国内，v5 口径，仅作方法论示例）**

| 层级 | 口径 | 估算 |
|---|---|---|
| TAM | 中国 18–35 岁有情绪陪伴需求的网民 | ~2.5 亿人 |
| SAM | 一二线城市、有付费习惯、愿用 AI 的年轻人 | ~3000 万人 |
| SOM | 首年靠自然增长+内容获客，保守渗透 0.3% | ~9 万人 |

> 面试时说"我按 TAM/SAM/SOM 三层做了粗算"——**重点是逻辑，不是数字**。
> 海外的 SAM 我没有可靠数据源，就诚实说"没有"，这比套一个中国数字更专业。

## 3. 成本模型（AI PM 必会的账）

> **2026-11-17 口径修正**：本节 §3.1–3.3 是 **v5 云端口径**的成本算法，保留作方法论。
> **v6 是端侧推理，每轮边际成本 = 0**，成本变成固定项（模型研发 + 分发 + 包体）。
> 讲 v5 这套账时必须带上"v5 云端"四个字；讲现在的成本，用下面这一段。

**v6 现行的账（一段话）**

```
推理在手机里完成 → 每轮没有 token 费用 → 边际成本 = 0
成本变成：
  ① 固定研发：模型选型、量化、端侧移植
  ② 分发：1.07 GB 安装包的应用商店带宽 / 存储
  ③ 支持：审核、客服、合规
所以 v6 的生死线不是 token 价格，是"有多少人愿意下载 1.07 GB 的包"。
```

### 3.1 单轮对话成本公式（v5 云端，历史口径）

```
单轮成本 = (输入 token × 输入单价) + (输出 token × 输出单价)
         + RAG 检索成本 + 存储成本摊销
```

### 3.2 一个具体的账（用 DeepSeek 级别价格举例，实际以官网为准）

**假设（v5 时期与 `prompts/02` 的 token 预算表一致，全项目只维护这一个口径；`prompts/` 已随 v5 移出仓库）：**
- 输入单价 ≈ ¥2 / 百万 token
- 输出单价 ≈ ¥8 / 百万 token
- 单轮输入 ≈ **2040 token**（人格卡 ~540 + 归因与追问 ~340 + 禁止项与规则 ~620 + 记忆 300 + 摘要 200 + 近期对话 400，见 v5 的 `prompts/02`，已移出仓库）
- 单轮输出 ≈ **200 token**（v2 后回复变短，多数轮 1–2 句）

> ⚠️ **早期版本这里写的是 1200 / 250 token，算出的 89% 毛利是错的。**
> 因为那份数没算上"归因层"新加的 340 token 和完整禁止项清单。
> 面试时如果被追问口径，必须以 v5 的 `prompts/02` 预算表为准——**那是当时唯一的数据源**。

**计算：**
```
单轮输入成本 = 2040 / 1,000,000 × 2  = ¥0.00408
单轮输出成本 = 200  / 1,000,000 × 8  = ¥0.00160
────────────────────────────────────────────
单轮成本 ≈ ¥0.00568  （约 0.57 分钱）
```

**放大到用户：**
```
人均每天 15 轮 × ¥0.00568        = ¥0.0852 / 天
                                 = ¥2.56 / 月

DAU 10,000 × ¥2.56               = ¥25,600 / 月（≈ 2.6 万元/月）
```

**结论（修正后）：**
- 单人月 token 成本约 **2.56 元**
- 若定价 ¥18/月，**毛利率 ≈ 85.8%**（(18 − 2.56) / 18）
- 但这只是 token 口径。**加上获客成本摊销后，毛利率会显著下降**：

| 场景 | CAC | 按 6 个月摊销 | 毛利率 |
|---|---|---|---|
| 自然增长/内容获客 | ¥5 | ¥0.83/月 | **81.2%** |
| 应用商店投放 | ¥30 | ¥5.00/月 | **57.9%** |
| 买量（高竞争期） | ¥80 | ¥13.33/月 | **11.7%** |

> 💡 **这张表比一个 89% 有用得多。** 它说明的不是"AI 产品很赚钱"，
> 而是"**这个生意的生死线在获客成本，不在 token**"。

> 💡 **面试杀手锏（这段话现在才站得住）**：
> "我按 prompt 的真实 token 预算算过账：单轮 0.57 分，单人月成本 2.56 元，
> 定价 18 元的话 token 口径毛利 85.8%。
> 但这个数字没什么意义，因为**加上获客成本就完全不一样了**——
> 如果是内容自然增长，CAC 5 块，毛利还有 81%；
> 如果是买量，CAC 80 块，毛利只剩 11%。
> 所以陪伴产品的生死线不是 token 价格，是**能不能不靠买量获客**。
> 这也是我把内容种草放在第一位、而不是投放的原因。
> 而内容能不能成，又取决于留存——所以我优先投记忆，因为留存是这个飞轮的起点。"

### 3.3 成本优化的 5 个杠杆（面试常问"怎么降本"）

| 杠杆 | 做法 | 效果 |
|---|---|---|
| **1. 分级模型** | 简单闲聊用小模型，深度共情用大模型 | 成本降 40–60% |
| **2. 压缩人格 Prompt** | 人格卡精炼，把长描述转 Few-shot 示例 | 输入 token 降 30%+ |
| **3. 记忆选择性注入** | 不把所有记忆塞进上下文，只检索 top-3 | 输入 token 降 50% |
| **4. 会话摘要** | 长对话定期摘要，不保留全量历史 | 长会话成本线性→常数 |
| **5. 缓存** | 高频开场/通用回复做模板缓存 | 冷启动成本降 |

## 4. 时机判断：为什么是现在

| 维度 | 判断 |
|---|---|
| **技术成熟度** | ✅ 模型共情能力、长上下文、结构化输出已足够 |
| **成本** | ✅ token 价格两年内下降 1–2 个数量级，陪伴这种高频场景才跑得通 |
| **用户心智** | ✅ 年轻人已习惯跟 AI 聊天，"电子布洛芬"成为网络共识 |
| **竞争** | ⚠️ 大厂在下场，但**细分场景还没人做透** |
| **风险** | ⚠️ 监管对"情感诱导"趋严，边界设计必须前置 |

## 5. 风险清单（诚实列出来，面试很加分）

| 风险 | 等级 | 表现 | 应对 |
|---|---|---|---|
| **安全风险** | 🔴 高 | 自伤内容未识别 | 四层防御 + 人工兜底（见 docs/05） |
| **留存风险** | 🔴 高 | 新鲜感过后流失 | 记忆 + 主动关怀 + 情绪曲线 |
| **合规风险** | 🟡 中 | 未成年人、情感诱导 | 年龄识别 + 功能降级 + 内容审计 |
| **同质化** | 🟡 中 | 大厂复制 | 深耕细分场景 + 数据飞轮（情绪日记） |
| **成本失控** | 🟢 低 | 重度用户成本过高 | 分级模型 + 用量上限 |
