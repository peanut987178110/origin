# 潮汐 v4.1 陪伴空间：需求与使用说明

本次参考林间聊愈室的功能方向，沿用潮汐自己的角色、页面与文案。

安装包：dist/潮汐Tide-v4.1.0.apk（约 485 MB）。默认手机内置模型，无需 API Key。旧版云设置仍可选。Android 7.0+，arm64-v8a / x86_64，建议至少预留 1.5 GB 空间。

| 入口 | 实际行为 | 边界 |
|---|---|---|
| 今晚先到这 | 将最近三条用户消息保存为当日日记，同日再次保存更新原卡；排除危机词表命中消息 | 原话摘录，不是模型总结；每条最多300字符、最多90张卡 |
| 来信与日记 | 查看、删除日记；下次进入聊天显示未读寄语并标记已读 | 固定角色寄语，已在界面标注，不虚构为AI定制来信；不做后台推送 |
| 心情周历 | 查看最近七个自然日，选择低落/紧绷/平静/轻松/开心 | 用户自评，每日可修改；没有诊断或抑郁指数 |
| 晚安工具箱 | 呼吸、回到眼前、放下忙碌、角色晚安四项练习，可朗读与停止 | 固定引导，系统TTS是否联网由系统决定 |
| 记忆本 | 手动添加、删除最多8条事实，每条最多80字符，随本地/云提示传入 | 与云端历史自动提炼的记忆是不同存储；删除此处不等于删除历史聊天和云端自动记忆 |

## 数据与交互
所有新增内容按本地账号隔离，无后台账号或跨设备同步。清空聊天不会清空日记、心情与记忆本；分别在对应入口删除。卸载清除本机应用数据。云模式下手动记忆会发给用户配置的服务商。
