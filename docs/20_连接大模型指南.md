# 20 · 连接大模型指南（手机直连）

> 潮汐 v3 不需要电脑：在手机上选服务商、填自己的 API Key，就直接和 DeepSeek / 通义 / Kimi 等大模型对话。

---

## 一、三步连上

```
① 去服务商官网注册 → 实名 → 创建 API Key（形如 sk-xxxxxxxx）
② 打开潮汐 → 设置 ⚙ → 大模型 → 选服务商 → 粘贴 Key
③ 点「保存并测试连接」→ 看到「连接成功 ✓」就能聊了
```

地址和模型名都预填好了，**一般只需要粘贴 Key**。

> 第一次注册时会自动走到「连接大模型」这一页，不用去设置里找。
> 想先看看界面也行，点「先跳过，稍后在设置里配置」。
> 没配好之前发消息，会明确提示"还没连接大模型"，不会假装回答。

## 三、为什么一套代码能连这么多家

这些服务商都兼容 **OpenAI 的接口格式**：

```
POST {接口地址}/chat/completions
Authorization: Bearer {API Key}
{"model": "...", "messages": [...], "stream": true}

→ 返回 SSE 流：
data: {"choices":[{"delta":{"content":"听你"}}]}
data: {"choices":[{"delta":{"content":"说这个"}}]}
data: [DONE]
```

所以**换服务商 = 换地址 + 换 Key + 换模型名**，代码不用改。

各家的细微差异由 `LlmClient.kt` 兼容处理（都有单测覆盖）：

| 差异 | 处理 |
|---|---|
| `data: {...}` 和 `data:{...}`（有无空格） | 都认 |
| 推理模型（deepseek-reasoner）先吐 `reasoning_content`，`content` 为 null | 跳过，不显示成 "null" |
| 有的服务商流结束不发 `[DONE]` | 流读完也算完成 |
| 本地 Ollama 不需要 Key | Key 为空时不发 Authorization 头 |
| 推理模型回复里夹 `<think>...</think>` | 页面清洗掉 |

## 四、API Key 安全

| 设计 | 说明 |
|---|---|
| **加密存储** | Key 存在 Android Keystore 派生密钥加密的 `EncryptedSharedPreferences` 里 |
| **只进不出** | 页面只能"存 / 问有没有 / 看打码"，**拿不到明文**。发请求时原生层自己取 Key 加到请求头 |
| **打码显示** | 设置里只显示 `sk-t****3456` |
| **按账号隔离** | 同一台手机多个账号，各自的 Key 互相看不到 |
| **不备份** | `allowBackup="false"`，Key 和对话不会被云备份带走 |
| **只发给你选的服务商** | 潮汐没有自己的服务器，不经过任何中转 |
| **http 只允许局域网** | 公网地址必须 https；页面和原生层双重校验，防止 Key 和对话明文外泄 |

> 面试怎么讲："API Key 我设计成'只进不出'：WebView 页面可以存 Key、可以问有没有，但拿不到明文。真正发请求时由原生层取出来加到请求头。这样即使页面被注入脚本，Key 也偷不走。"

## 五、常见问题

| 看到的提示 | 原因 | 怎么办 |
|---|---|---|
| API Key 不对或已失效 | 401 | 重新复制 Key，注意不要带空格 |
| 账户余额不足或额度用完了 | 402 | 去服务商后台充值，或换一家有免费额度的 |
| 请求太频繁被限流了 | 429 | 等几秒再发 |
| 模型名不对 | 404 | 点「获取列表」选一个 |
| 连不上服务商 | 网络 | 检查手机网络；OpenAI 国内通常不通 |
| 公网地址必须用 https | 填了 http:// 公网地址 | 改成 https:// |
| 地址填到 /v1 为止 | 把 `/chat/completions` 也填进去了 | 删掉末尾那段 |

## 六、对话数据去哪了

```
你在手机上打字
   │
   ├─ 危机关键词 → 不发给任何人，本地直接给热线（docs/12）
   ├─ "你还记得…"且记忆里没有 → 本地直接回"不太记得了"，不发给模型
   │
   └─ 其他 → 角色提示词 + 最近 16 条对话 + 长期记忆
             → 发给你选的服务商生成回复
             → 回复与对话只存在这台手机
```

**需要知道的一点**：对话内容会发给你选的服务商来生成回复，各家的数据政策不同。
最私密的选择是"电脑上的 Ollama"——数据不出你家的局域网。
